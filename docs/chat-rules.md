# 聊天助手的规则

聊天助手怎么说话，由 `content/agent.json` 决定。在 /admin 里打开 **Chat assistant** 就能编辑，保存后网站重新部署，下一次回答就按新规则来。

| 栏目 | 作用 |
|---|---|
| Always do | 每次都要做的事，比如"用第一人称" |
| Never do | 绝对不能做的事，比如"不说日期" |
| Tone | 语气，比如"简短"、"问中文就答中文" |
| Topics to decline | 不想聊的话题，加上婉拒时说的话 |
| Fixed answers | 固定回答：问题里出现任意一个触发词，就直接发你写的答案，不经过模型。可以另写一份中文答案，问题是中文时用它 |

建议：每条规则只写一句话，只放真正重要的。规则太多的话，9B 小模型反而记不全。

## 写在代码里的规则（不在后台）

这些是安全底线，放在 `worker/index.js` 里，免得被误删：

- 只用网站内容回答，不编造项目、数字和链接。
- 私有仓库只说简介和 README，不给链接，不引用代码。
- 提到项目时用准确的项目名，这样右边面板才能打开它。

另外 `worker/agent.js` 的 `scrubDates()` 会在每条回答发出去之前删掉其中的日期，就算模型没听话，访客也看不到。

改完规则后，按 [bad-cases.md](bad-cases.md) 跑一遍检查。
